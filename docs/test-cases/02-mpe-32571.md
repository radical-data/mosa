# Case 02: MPE 32571

## Purpose

Test conflicting names and interpretations without forcing one preferred account.

## Entities

- **Item:** MPE 32571
- **Agent:** Museo delle Civiltà
- **Place:** Rome
- **Sources:** Museum record or image; Paula's note

## Expected claims

- Paula’s note `refers_to` the item.
- The photograph `depicts` the item.
- The museum source `has_name` “Partoriente”.
- The museum source `classified_as` the item as “moai kava kava”.
- Paula’s note `described_as` the item as a woman with an elongated vulva.
- The museum is connected through external identifier `MPE 32571`.
- The item is `held_by` the Museo delle Civiltà.
- The item is `located_at` Rome.

## Questions

- Can contradictory or incompatible interpretations coexist?
- Can display avoid privileging one unsourced label?
- Can source wording be preserved without becoming MoSA's conclusion?
- Can one source support several claims about the same item?

## Pass condition

No single name or classification overwrites the others, and every interpretation remains attributable to its source.

## Implementation findings

- Competing descriptions and classifications coexist without being resolved by MoSA.
- Display labels are presentation projections from attributed `has_name` claims or identifiers; no stored working label privileges one interpretation.
- Museum statements reported through Paula’s note use `mentions`.
- Paula’s own interpretation uses `supports`.
- A source link to a photograph does not by itself prove that the photograph depicts the item.
- Visual sources support their own `depicts` claims directly.

## Result

Pass. No schema change required.
